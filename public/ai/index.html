Notable work

  • Corporate infrastructure built from scratch, turnkey — 4 sites across 2 countries, 100–200 users, 50+ servers. Active Directory, Exchange with DAG between sites, mail pipeline on Proxmox Mail Gateway + HAProxy with SNI routing, multi-site routing on WireGuard + GRE + OSPF via FRRouting, MikroTik RouterOS 7, and an ACME → Exchange certificate automation pipeline. Delivered solo, end to end.
  • 2FA and SSO for corporate mail — a custom Keycloak based 2FA provider, with ANGIE in front of OWA and Outlook clients handling SSO at the web-server layer. No changes to Exchange internals. Running in production, carrying all corporate mail traffic.

Every change with a backup and rollback path, across hundreds of GPOs.
  • Multi-agent development workflow — three specialised AI agents (strategy, knowledge base, in-IDE developer) communicating through an MCP Memory Server and a shared knowledge layer.
  • Office-to-datacenter networking — site-to-site IPSec across offices and two datacenters, redundant links, internet connectivity cost reduced by roughly 66%.
